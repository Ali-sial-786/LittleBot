# Recorded voice clips

Clips here replace a built-in sound of the same name: `giggle_1.wav`, `giggle_2.wav`, ... are played
(one at random) wherever LittleBot plays "giggle" (tapping the face, games, activities). Delete them to
get the synthesised sound back.

`giggle_*.wav`: "Hehe! That tickles!", "Hee hee hee! That tickles!", "Hehehe, stop, that tickles!",
made with the Kokoro-82M text-to-speech model (Apache-2.0, voice `af_heart`), 22.05 kHz mono.
